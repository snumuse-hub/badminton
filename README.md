# 🎯 AI 경기 분석 (배드민턴 · 탁구)

경기 영상을 브라우저에서 실시간으로 분석하는 웹앱입니다. 첫 화면에서 종목을 고르면 그 종목에 맞게 분석합니다.

**사용하기:** https://snumuse-hub.github.io/badminton/

| | 🏸 배드민턴 | 🏓 탁구 |
|---|---|---|
| 보정 | 복식 코트 바깥 모서리 4곳 | 탁구대 윗면 4곳 (전체 또는 내 쪽 절반, 높이 76cm 자동 반영) |
| 맵 | 코트 맵 | 탁구대 + 주변 바닥 맵 |
| 공 분석 | – | 업로드 영상에서 스트로크 자동 카운트, 바운드 위치에 원 표시 |

공통 기능
- 실시간 카메라 / 영상 파일 업로드
- 선수 최대 4명 감지·추적 (MediaPipe Pose)
- 이동 거리(m), 속도, 활동량 지수, 위에서 본 맵과 이동 경로
- 랠리 시간, 샷 카운트(수동), 랠리 기록

파일 구성: `index.html` (종목 선택) · `analyze.html?sport=badminton|tabletennis` (분석) · `ball-core.js` (탁구공 검출·궤적 분석)

탁구 공 분석은 카메라를 고정하고 탁구대를 옆에서 찍은 영상에서 가장 정확합니다. 30fps 영상에서도 동작하며, 슬로모션(60fps 이상)이면 더 정확합니다.

카메라는 https 주소에서만 동작합니다.
